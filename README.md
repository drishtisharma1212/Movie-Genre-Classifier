# Movie-Genre-Classifier
A Python Machine Learning project that predicts movie genres based on movie descriptions.

## Features
 Predicts:
 <br>
     Action
    <br>
     Horror
    <br>
     Comedy
    <br>
 Uses TF-IDF Vectorization
 <br>
 Uses Logistic Regression
 <br>
 Includes confidence score
 <br>
 Fully Python-based
 <br>

## Technologies Used
<br>
 Python
 <br>
 Pandas
 <br>
 Scikit-learn
 <br>
 Joblibs
